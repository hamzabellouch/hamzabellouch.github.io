Our Projects

VMP

VMP is an ultra-native, high-performance C++ media engine and benchmarking suite for Linux. Engineered for flawless 4K/8K/16K playback, zero frame drops, microsecond-accurate audio sync, and GPU hardware decoding (VA-API / NVDEC), featuring both a modern OpenGL GUI and a standalone headless CLI.

AI Spark

AI Spark is a local FastAPI web application that lets you simultaneously broadcast queries to multiple AI chat interfaces (ChatGPT, Gemini, DeepSeek) running inside your browser. It displays responses side-by-side in a beautiful comparison grid and synthesizes a unified answer.

Omicron

Omicron is a next-generation Android media downloader powered by yt-dlp & gallery-dl. Download videos, audio, images and playlists ( with subtitles, dub and metadata ) + a clean Material Design 3 interface.

Apex

Apex is an Android application designed to manage system resources, analyze installed apps, and free up storage space by safely automating cache cleanup and background app management.

Links

Links is an open-source Android application designed to scan, generate, and manage custom QR codes and short URLs, featuring link safety inspection and enhanced link security within a modern, clean interface.

Gallery

An open-source, ultra-fast Android gallery application powered by Jetpack Compose, Material 3, and Media3 ExoPlayer with 4K video playback, deep zoom, and dynamic theming.

Ren Browser

A fast, privacy-focused Android browser built for lightweight web navigation with built-in protection, tab management, and smooth performance.

ARUT

Privacy Policy

Last Updated: October 2, 2026

At Hamza Bellouch (tknoglobal), privacy is not an afterthought—it is the foundational core of everything we build. All our applications, software suites, tools, and projects operate under strict zero-tracking, zero-ad, and 100% on-device principles.

0. Rule 0: Disclaimer on Modified Builds, External Binaries & Unofficial Forks

Original Source Integrity: This privacy policy, safety guarantees, and security features apply strictly and exclusively to official, unmodified application binaries, software packages, installers, scripts, extensions, and source code distributed directly through our official repositories (github.com/hamzabellouch) and verified releases.

Zero Liability for Modified / External Builds: We (the publisher and maintainer) assume no responsibility or liability whatsoever for any modified packages, third-party forks, repackaged binaries, unofficial distribution channels, or altered projects not originating directly from our official repositories. Any installation or use of modified, tampered, or third-party builds is entirely at your own risk, and the publisher assumes no responsibility for any consequences, damages, security compromises, or data breaches that may occur.

1. Executive Summary & Universal Ecosystem Overview

Our entire software portfolio—encompassing mobile apps, desktop programs, media engines, AI orchestrators, system utilities, security frameworks, command-line tools, and browser extensions across Android, Linux, Windows, and Web—is engineered from the ground up to prioritize user privacy, absolute data sovereignty, and uncompromised performance.

Core Privacy Commitment: All our tools, programs, and applications operate 100% locally on your device. We do not collect, store, transmit, share, profile, or monetize any personal data, device identifiers, system logs, hardware streams, files, or user inputs to external analytics servers or third parties.

2. Information Processed On-Device

To deliver core functionality, our software reads and processes the following information strictly on your local machine:

  • Hardware & Media Streams: Any live device input (such as camera feed, audio stream, or GPU frame buffer) is processed strictly in real-time in volatile memory (RAM) and immediately discarded. Streams are never saved, recorded, or transmitted without explicit user command.
  • User Inputs, Queries & Files: Text strings, files, commands, AI prompts, or URLs provided by the user are computed locally or routed strictly to endpoints configured by the user, without any central telemetry or logging.
  • Local Storage & Preferences: User settings, history logs, caches, and customized parameters are stored strictly locally on your machine or device storage.

3. System Permissions & Privileges

Our software only requests operating system privileges strictly required to carry out the specific features requested by the user:

Hardware & Device Access

Used strictly in real-time when actively triggered by the user for media playback, capture, or processing. Never accessed or recorded silently in the background.

Network & Connectivity

Utilized solely for user-initiated network requests (such as downloading files, resolving endpoints, or checking official updates on GitHub) with zero telemetry sent.

File System & Storage

Used strictly to read or write files explicitly chosen by the user, manage application cache, and save exported data. No unauthorized disk indexing takes place.

System Notifications & Status

Displays user-visible progress indicators, task completions, and essential operational status alerts on supported operating systems.

4. Safe Network & Resource Inspection

Whenever our utilities inspect or interact with network resources, they inspect only direct protocol responses to fulfill the user's task. Our software never reads, intercepts, or extracts private cookies, authentication credentials, or browsing history.

5. Zero Ads & No Tracking

Zero third-party analytics SDKs, zero telemetry collectors, and zero ads. We do not participate in behavioral tracking, device fingerprinting, or user profiling across any of our software solutions.

6. Data Retention & Deletion

All transient memory buffers are cleared instantly from RAM. Uninstalling any application or deleting its configuration folder permanently and completely purges all local history and preferences.

7. Managing Permissions & User Sovereignty

You maintain full control over all operating system permissions and tool execution. You can modify or revoke permissions at any time through your operating system settings.

8. Contact & Developer Support

If you have questions or feedback regarding this Privacy Policy across any of our software products, feel free to reach out directly.
