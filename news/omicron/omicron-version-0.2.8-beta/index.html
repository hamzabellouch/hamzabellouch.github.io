Omicron v0.2.8-beta

Hamza Bellouch
CEO & Founder of tknoglobal

We are excited to announce Omicron v0.2.8-beta (Early Access 23)! This release focuses on polished UI refinements across the downloads list, settings, and dialogs — including a clean history export format, smarter button layouts, improved rename dialogs, one-tap settings backup with .omicron files, and an SD card storage toggle.

UI Polish, Settings Backup & Download Directory Enhancements

Omicron v0.2.8-beta brings a focused round of UI refinements and usability improvements. Download history exports now use a clean date-stamped filename format. The downloads list is tidier with favorited items staying in place and the bottom empty space removed. Settings dialogs have been redesigned for consistency — the Custom Theme dialog gets an Edit button and primary-blue Add styling, while the Rename Item dialog dynamically expands up to three lines. A new 3-dots top menu in Settings enables one-tap backup and restore of all app preferences and custom templates via .omicron files. The download directory settings gain an SD card storage toggle and a refreshed output template icon, with the pre-download configuration dialog restored for full format control before each download.

Changes — July 16, 2026

  • Exported download history files are now saved with a clean date format (History-DD-MM-YYYY.txt).
  • The "Download playlist" option has been moved above "Rename file on storage" in the Advanced settings section.
  • Swapped the "Rename" and "Remove" buttons in the item menu and highlighted "Remove" with a filled red design.
  • Favorited items now remain in their original position in the downloads list instead of moving to the top.
  • Removed the large empty space at the bottom of the downloads list for a cleaner layout.
  • Standardized the Delete button styling in the Custom Theme dialog to match the primary app colors.
  • Improved the Rename Item dialog text box to start as a single line and expand dynamically up to three lines based on text length.
  • Relocated the Edit Shortcuts button below the shortcuts list in the template editor and updated the section header color.
  • Added an Edit button to the Custom Theme dialog and styled the Add button with the primary blue color.
  • Temporarily disabled the Image Folder option in the download directory settings.
  • Display English as a clean language option without regional country suffixes.
  • Restore the pre-download configuration dialog for customizing download types and formats before downloading.
  • Added a 3-dots top menu in Settings to easily back up and restore all app preferences and custom templates using .omicron files.
  • Added a toggle in Download Directory settings to save media directly to /storage/emulated/0/Omicron/ instead of the Download folder, disabled by default.
  • Updated the Output Template icon in Download Directory settings to a clean document design.
  • Added a description explaining the option right above the active status text in Network settings for Concurrent Video Downloads.
  • Changed the Preset setting icon in the download configuration screen to a lightning bolt.
