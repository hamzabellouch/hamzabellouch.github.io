Omicron v0.4.6-beta

Hamza Bellouch
CEO & Founder of tknoglobal

We are excited to announce Omicron v0.4.6-beta! This release delivers a sweeping set of UX refinements spanning playlist grouping for images and videos, an interactive Status page viewer, quick-clear controls across all input fields, smarter download directory management, Material 3 upgrades, IME keyboard fixes, and a fully revamped Troubleshooting section with new developer profile cards.

Playlist Grouping, Image Downloads & Status Viewer

Omicron v0.4.6-beta introduces powerful playlist grouping on both the Home page and in the Downloads library. Active multi-image downloads of 4 or more items are consolidated into a single card with an IMAGES badge, while completed images group into a playlist-style card with a dedicated sub-page. YouTube video playlists with 4 or more videos get the same treatment with a VIDEOS badge and an expandable bottom sheet for per-video control. The completely redesigned Status page viewer adds a horizontal swipe pager, an interactive dots indicator, tap-to-toggle video playback, a scrubbable seek bar with live timestamps, and full gesture-based browsing in the Saved tab.
