Omicron v0.4.2-beta

Hamza Bellouch
CEO & Founder of tknoglobal

We are excited to announce Omicron v0.4.2-beta! This release delivers a sweeping SD Card integration for WhatsApp status saving, a revamped Profile screen with a dedicated Report Problem action, an updated Sponsors screen, and a comprehensive visual overhaul introducing flat capsule-shaped buttons and unified 20dp rounded corners across every screen in the app.

SD Card Status Saving & Unified Capsule UI

Omicron v0.4.2-beta extends the WhatsApp Status saver with full SD Card support via the Storage Access Framework, allowing statuses to be saved, displayed, deleted, and shared directly from external storage — on par with internal storage behavior. Alongside this, a cohesive visual language lands across the entire application: input fields, dialogs, floating buttons, and action bars all adopt smooth capsule shapes with unified 20dp rounded corners, while the Download and Paste buttons gain a modern flat appearance free of drop shadows.

Changes — October 18, 2026

  • Added a dedicated Status Folder preference in Download Directory settings.
  • Integrated the Status Folder with SD Card download behavior matching Video, Audio, and Image folders.
  • Enabled saving WhatsApp statuses directly to SD Card using Storage Access Framework.
  • Updated the Saved statuses tab to recognize and display media stored on SD Card.
  • Implemented deletion and sharing support for status files residing on SD Card.
  • Connected the Status Folder to the root internal storage reset and backup restoration.
  • Added the Report Problem action icon in the Profile screen alongside the Settings icon.
  • Updated the Sponsors screen with a GitHub Star button and a new sponsor interaction.
  • Updated the Download and Paste floating buttons with smoother 20dp rounded corners.
  • Converted the Download and Paste buttons to a modern flat appearance by removing drop shadows.
  • Applied the matching 20dp rounded corner shape to the Add Task button on the Running Tasks screen.
  • Flattened the Add Task button elevation to maintain consistent visual styling across screens.
  • Video duration badge displayed on video cards formatted as minutes and seconds.
  • Video thumbnails generated seamlessly using Coil video frame decoder.
  • Fixed media viewer presentation by disabling pinch-to-zoom gestures.
  • Centered single Save capsule button when previewing unsaved WhatsApp statuses.
  • Bottom action bar with Delete, Open, and Share buttons for saved media.
  • Relocated Open action button into a bottom capsule alongside Delete and Share.
  • Media filter chips for All, Images, and Videos restricted to the Saved section.
  • Prevention of selecting already saved items with an "Already saved" toast notification.
  • Smart Select All action that selects only unsaved statuses.
  • Support for multiple WhatsApp instances with dynamic custom tabs.
  • Dynamic capsule shape for the Home new download task input field with smooth transitions between single-line and multi-line states.
  • Dim placeholder displaying an example URL in the Home input field that stays visible on focus until typing begins.
  • Dynamic capsule styling and example URL placeholder applied to the new task dialog in the Running Tasks page.
  • Capsule shape styling for Profile input fields covering both Edit Display Name and Edit Username.
  • Capsule shape styling and dynamic multi-line curvature for Custom Command Template dialogs and pages.
  • Capsule shape styling across all Format Settings inputs covering video preferences, format sorting, subtitles, and audio dubbing.
  • Capsule shape styling across Download Directory settings for custom folder paths and filename templates.
  • Capsule shape styling across Network Settings dialogs for download rate limits and proxy configurations.
  • Capsule shape styling for General and Advanced settings inputs including auto-update intervals, SponsorBlock filters, and archive editing.
  • Capsule shape styling for Media and Download dialogs including playlist range selection, video trimming times, and file renaming.
  • Unified capsule shape default integrated into the core text field component across the entire application.
