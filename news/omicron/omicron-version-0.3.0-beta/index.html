Omicron v0.3.0-beta

Hamza Bellouch
CEO & Founder of tknoglobal

We are excited to announce Omicron v0.3.0-beta — Early Access 25, New Generation! This landmark release refactors the entire download module, hardens yt-dlp initialization and state management, achieves complete UI localization across 35 languages, unifies the backup system, and delivers a comprehensive sweep of UI polish, icon redesigns, and concurrent download safety improvements.

Download Module Refactor, Full Localization & yt-dlp Hardening

Omicron v0.3.0-beta fully refactors the download module by removing all legacy V2 suffixes and rebuilding missing interactive dialog components under a unified package. yt-dlp initialization is hardened with safe engine setup guards, clean reinstall state resets, and accurate version detection. Complete UI localization is achieved across all 35 non-English languages with automatic completion for every missing string key, XML syntax fixes for Tamazight and French resources, and removal of all pre-existing compiler warnings. The backup system is unified to cover the full application, with cookie profiles included alongside templates and shortcuts, and settings exported in standard JSON format.

Changes — August 10, 2026

  • Refactored the entire download module to remove all legacy V2 suffixes and clean up redundant wrapper files across the codebase.
  • Rebuilt missing interactive dialog components for notification permissions, playlist selections, and video clipping under the unified download package.
  • Verified build stability and codebase cleanliness through complete Gradle builds and unit test suite executions.
  • Hardened the yt-dlp initialization and execution logic to ensure safe engine setup before fetching media or running custom commands.
  • Implemented state resetting logic to allow clean yt-dlp reinstalls and updates without getting stuck in stale states.
  • Enhanced version detection and UI state synchronization so installed yt-dlp version details display accurately after updates.
  • Complete UI localization coverage for all 35 non-English languages, automatic translation completion for every missing string key across all resource files, XML syntax and encoding error fixes in the Tamazight and French resource files, and removal of all pre-existing compiler warnings across LanguageSettings, DownloadUtil, FileUtil, and UpdateUtil.
  • Removed the two horizontal divider lines enclosing the website and playlist checkboxes inside the subdirectory dialog.
  • Restricting the yt-dlp deletion process to remove only the yt-dlp subdirectory and its specific preferences to preserve the python, ffmpeg, and aria2c environments.
  • Redesigning the verification popup into a standard Material 3 AlertDialog layout that supports both enabling and disabling account verification.
  • Integrated Noto Sans Arabic font dynamically when the display language is set to Arabic.
  • Unified the backup import and export system across the entire application.
  • Removed the vertical divider next to the download archive preference switch in settings.
  • Reduced the maximum concurrent video downloads slider range limit to five.
  • Replaced the download format selection preset lightning bolt icon with a rocket launch icon.
  • Adjusted the top-right done button layout alignment by resolving layout shifting issues.
  • Configured the custom theme color dialog to conditionally toggle between add and edit actions.
  • Styled any preference component text containing Arabic characters with Noto Sans Arabic font dynamically.
  • Removed the redundant cancel option in the profile verification dialog.
  • Added inline icons for favorites and archives in empty download list state labels.
  • Replaced all solid archive and unarchive icons with their outlined versions.
  • Synchronized the additional settings chips visibility dynamically with the user selected download tab in the download dialog.
  • Modified the concurrent video downloads preference icon to switch between a layers icon when enabled and a cleared layers icon when disabled.
  • Adjusted the concurrent video downloads preference value range and slider configuration to start from two parallel downloads instead of one.
  • Updated the main title to semi-bold, changed the home icon to Material Design 3 style, eliminated touch vibration on the home tab, and increased the font weight of the navigation bar labels.
  • Replaced the three-dot menu icon on the Settings page top bar with a custom RuleSettings vector icon, and added a custom Downloading vector icon along with a filled state variant for the Downloads tab in the bottom taskbar and navigation rail.
  • Upgraded the overall application version to 0.3.0-beta.
