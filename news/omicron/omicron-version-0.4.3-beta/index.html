Omicron v0.4.3-beta

Hamza Bellouch
CEO & Founder of tknoglobal

We are excited to announce Omicron v0.4.3-beta! This release fundamentally restructures the engine architecture by moving to a fully on-demand installation model for yt-dlp and gallery-dl, introduces a powerful multi-tier thumbnail recovery system, adds direct SD Card staging for active downloads, delivers Instagram GraphQL carousel support, and brings a comprehensive set of download management, settings, and UX improvements.

On-Demand Engine Architecture & SD Card Staging

Omicron v0.4.3-beta completely removes all pre-bundled yt-dlp and gallery-dl binaries, shifting to a purely on-demand installation workflow. Users now explicitly install both engines from General Settings, while strict runtime checks prevent any execution before installation is confirmed. Downloads can now be staged directly to SD Card, eliminating internal phone storage consumption entirely, with dedicated SD Card thumbnail storage for instant image loading. A multi-tier thumbnail recovery system guarantees thumbnails are always restorable from embedded web links, local video frame extraction, or remote metadata refresh.

Changes — October 19, 2026

  • Completely removed all bundled binary files for yt-dlp and gallery-dl to eliminate pre-packaged offline copies.
  • Shifted to a purely on-demand installation workflow where users explicitly install both engines from General settings.
  • Added strict runtime checks in the engine core to prevent execution attempts when binaries are not installed.
  • Integrated user-facing alert prompts inside download dialogs guiding users to install the required engine first.
  • Prevented background auto-updaters from silently fetching tools before initial user installation.
  • Streamlined delete and reset actions to cleanly wipe engine storage without triggering fallback re-extraction.
  • Unified status labels across languages to consistently display "Click to install the latest version".
  • Dedicated reload thumbnail button placed next to the remove option in download history.
  • Embedded thumbnail URLs inside history records to guarantee thumbnails can always be restored.
  • Multi-tier thumbnail recovery system using web links, local video frame extraction, and remote metadata refresh.
  • Direct SD Card staging for active downloads to eliminate internal phone storage consumption entirely.
  • Dedicated SD Card thumbnail storage enabling instant image loading without cluttering internal memory.
  • Full backward compatibility fallback to reliably display all previously downloaded thumbnails.
  • Added a Reset Settings option in the Settings menu with an official Material Symbols icon.
  • Excluded user profile, WhatsApp status preferences, and download directories from being reset.
  • Updated the Cache Video Info icon to Tab Inactive and shortened its description to two lines.
  • Ensured incomplete, paused, and failed downloads stay permanently in Home until manually deleted.
  • Configured successfully finished downloads to leave Home cleanly and remain in Download History.
  • Protected the active download queue from being erased during settings resets.
  • Enhanced download task persistence with immediate saving and reliable restoration across app restarts.
  • Intelligent post text snippet extraction to generate clean and readable image titles.
  • Automatic fallback naming using the platform name and short numeric identifiers.
  • Dynamic account handle extraction from URLs replacing the generic gallery-dl label.
  • Removal of the center video play arrow overlay from completed image cards.
  • Direct card tap interaction to instantly open downloaded images in the system gallery.
  • Instagram GraphQL API integration in gallery-dl for full carousel and album downloads.
  • Modern browser user-agent emulation to avoid automated scraper restrictions.
  • Multi-photo carousel detection displaying the exact image count in the post.
  • Automatically dismiss and slide down the options bottom sheet upon tapping Reload Thumbnail in the downloads list.
  • Added tactile haptic feedback when selecting the thumbnail reload action.
  • Preserved background thumbnail reloading and toast notifications after the options sheet closes.
