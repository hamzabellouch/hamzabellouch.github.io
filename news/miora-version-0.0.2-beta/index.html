Miora v0.0.2-beta

Hamza Bellouch
CEO & Founder of tknoglobal

We are thrilled to announce Miora v0.0.2-beta! This major update transforms the sharing experience with system-wide Android Share Sheet integration, a live transfer session dashboard, batch file transfers up to 500 files, a brand-new Local Wi-Fi LAN protocol, Instagram-grade carousel support, and deep SD Card staging — all engineered for speed, reliability, and total offline privacy.

Share Sheet Integration, Batch Transfers & Local Wi-Fi LAN

Miora v0.0.2-beta introduces system-wide Android Share Sheet integration, automatically navigating to the Send screen with pre-selected files. Users can now transfer up to 500 files in a single Wi-Fi Direct session or 100 files over Bluetooth, with high-performance list recycling and thumbnail caching optimized for hundreds of items. A dedicated third protocol — Local Wi-Fi LAN — is introduced with intelligent automatic fallback to Wi-Fi Direct on connection failure, isolated from home router interference, and hidden behind a Settings toggle until explicitly enabled.

Changes — October 19, 2026

  • System-wide Android Share Sheet integration for all media and files.
  • Automatic navigation to the Send screen with pre-selected shared files.
  • Interactive transfer protocol selection capsule for Wi-Fi Direct and Bluetooth.
  • Live transfer session dashboard displaying progress, transfer speed, and completed item count.
  • Floating square add button allowing users to append more media during an active session.
  • Batch file transfer support up to 500 files for Wi-Fi Direct and 100 files for Bluetooth.
  • High-performance list recycling and thumbnail caching optimized for hundreds of files.
  • Kernel-level exact file size resolution fixing video transfer stalls.
  • Protocol-optimized socket buffers and periodic stream flushing to ensure transfer stability.
  • Live active card preview on the receiver screen replacing the infinite loading spinner.
  • Scoped storage file saving with MediaScanner integration for immediate appearance in gallery.
  • Automatic connection teardown upon exiting screens to prevent conflicts and save battery.
  • Filter tabs reorganized into Received and Sent with Received selected by default.
  • Individual card rendering for each transferred file rather than grouping them into a single card.
  • Removal of redundant share buttons on media cards in favor of a unified options menu.
  • Removal of the top clear-history icon for a cleaner top bar layout.
  • Added a third dedicated transfer protocol for Local Wi-Fi LAN.
  • Introduced a toggle in General Settings kept disabled by default.
  • Kept the Local Wi-Fi protocol completely hidden until explicitly enabled.
  • Isolated pure Wi-Fi Direct transfers from home router network interference.
  • Implemented automatic fallback from Local Wi-Fi to Wi-Fi Direct upon connection failure.
  • Prevented home router IP leakage inside Wi-Fi Direct QR codes and BLE beacons.
  • Fixed and smoothed live transfer speed calculation for Bluetooth and Wi-Fi.
  • Enabled automatic radar scanning and peer discovery over local LAN networks.
