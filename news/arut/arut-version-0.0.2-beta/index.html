ARUT v0.0.2-beta

Hamza Bellouch
CEO & Founder of tknoglobal

We are pleased to release ARUT v0.0.2-beta! This release fixes shell script interpreter execution on Linux and macOS, converts line endings to Unix LF, adds static musl 64-bit Linux Rust relay compilation, cleans distribution launcher templates, and automates bundle packaging.

Linux & macOS Script Fixes and Static Musl Rust Relay

ARUT v0.0.2-beta resolves shell script execution issues by fixing shebang directives, removing CMD-style caret escape characters, and adopting POSIX command substitution syntax. All shell files now use strict Unix LF line endings backed by repository .gitattributes. In addition, the Rust relay server is now natively compiled for 64-bit Linux with the static musl target for maximum distribution portability.

Changes — October 09, 2026

  • Fixed the broken shebang across all shell scripts by adding the missing exclamation mark to form a valid shell interpreter directive.
  • Removed all invalid Windows CMD caret escape characters from bash scripts to ensure variables are evaluated properly.
  • Fixed script directory detection by using standard POSIX command substitution syntax.
  • Converted line endings for all Linux and macOS scripts from Windows CRLF to Unix LF format.
  • Added a repository .gitattributes file to ensure Git preserves Unix LF line endings on all operating systems.
  • Compiled the missing 64-bit Linux ELF executable for the Rust relay server using the static musl target for maximum distribution compatibility.
  • Packaged the compiled Rust Linux binary into the standalone Linux and multi-platform distribution folders and zip archives.
  • Created organized and clean launcher script templates inside the tools directory.
  • Updated the Windows and Linux distribution build scripts to copy tested templates and package complete release bundles.
  • Added automated zip compression for all target release packages.
