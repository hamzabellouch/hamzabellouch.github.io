Gallery v0.0.4-beta

Hamza Bellouch
CEO & Founder of tknoglobal

We are thrilled to present Gallery v0.0.4-beta! This major update brings a high-performance 4K/8K/16K viewport tiling engine, smooth pinch-to-zoom transitions, standardized floating capsule glassmorphism across all viewers, full Light Mode adaptation, strict memory hardening, and seamless 120Hz fling scrolling.

Viewport Tiling Engine, Deep Zoom & Memory Optimization

Gallery v0.0.4-beta introduces a true multi-resolution viewport image tiling engine powered by BitmapRegionDecoder and a dynamic 512x512 tile grid with bounded LRU caching. Users can now zoom smoothly up to 20x on 4K, 8K, and 16K ultra-high-resolution images while maintaining a lightweight 30–40MB tile memory footprint without OpenGL texture limits or crashes.

Changes — September 30, 2026

  • Removed the 3-dots overflow menu and multi-selection mode from the Albums tab for a cleaner and more streamlined browsing experience
  • Fixed frame stuttering during high-bitrate FHD (1080x1920) video playback by enabling asynchronous MediaCodec buffer queueing and uncapped dynamic buffering
  • Implemented smooth progressive pinch-to-zoom with continuous scaling and animated double-tap zoom transitions between 1x and 3x
  • Eliminated pinch-zoom freezes and improved zoom responsiveness in the high-resolution image viewer
  • Updated the SD card album indicator to the official Material Symbols Outlined sd_card icon
  • Removed surrounding backgrounds and shadows from the SD card indicator for a clean standalone icon appearance
  • Added Favorites Export and Import functionality using .txt files through the Android Storage Access Framework
  • Added "Export favorites" and "Import favorites" actions above "Select items" when the Favorites filter is active
  • Set "Show resolution badges" to Off by default for a cleaner media grid
  • Set "Rounded corners" to Off by default for media cards
  • Fixed fullscreen UI toggling while zoomed in without resetting zoom level or viewport position
  • Integrated system touchSlop calibration to distinguish intentional taps from microscopic finger movement during active zoom
  • Improved 1-finger panning and 2-finger pinch-to-zoom interoperability
  • Prevented zoom gestures from accidentally triggering fullscreen toolbar visibility changes
  • Isolated double-tap handling to preserve instant 1x ↔ 3x zoom transitions without interfering with single-tap controls
  • Standardized floating capsule glassmorphism across the application with a consistent 94% translucent background, 6dp ambient shadow, and 0dp tonal elevation
  • Updated the bottom navigation taskbar capsule to match the main header capsule styling and elevation
  • Converted media viewer back navigation and top utility actions into matching floating pill capsules
  • Added theme-adaptive styling to media viewer top action capsules for Light and Dark modes
  • Converted the media viewer bottom action bar into a unified floating capsule containing Share, Edit, Favorite, Trash, and Details controls
  • Updated the Shorts video player floating back button to match the unified capsule design language
  • Implemented a true 4K, 8K, and 16K viewport-based image tiling engine using BitmapRegionDecoder
  • Added a dynamic 512x512 tile grid with bounded LRU caching for ultra-high-resolution image rendering
  • Enabled smooth deep zooming up to 20x while maintaining a 30–40MB tile memory footprint
  • Eliminated OpenGL texture-size limitations and prevented crashes when displaying extremely high-resolution images
  • Refactored Coil memory caching to use the runtime JVM maximum heap ceiling instead of total device RAM
  • Hardened the memory architecture against oversized cache allocation and OutOfMemory conditions
  • Added centralized onTrimMemory and onLowMemory handling for proactive memory recovery under system pressure
  • Automatically evict Coil image caches and purge L1 thumbnail caches during memory pressure events
  • Converted the thumbnail cache into a strict 24MB byte-budgeted LRU cache with immediate eviction
  • Reduced background thumbnail memory consumption by more than 150MB through bounded cache management
  • Added resolution-aware thumbnail interception so requests above 768px or Size.ORIGINAL bypass the thumbnail fetcher and decode at full resolution
  • Upgraded image editing export to a single-pass rendering pipeline combining rotation, cropping, and color matrix transformations
  • Added immediate source bitmap recycling after export rendering to prevent memory spikes during editing of 48MP and 108MP photos
  • Hardened high-bitrate 4K and 8K video muxing with dynamic buffer sizing derived from track metadata and a 4MB minimum baseline
  • Eliminated BufferOverflowException during extraction of high-bitrate video streams
  • Optimized media grid thumbnail rendering with HARDWARE and RGB_565 bitmap configurations
  • Reduced thumbnail memory usage by up to 50% while improving high-speed grid scrolling performance
  • Improved thumbnail rendering for smooth 120Hz fling scrolling across supported devices
  • Added an adaptive Timeline FastScrollbar that automatically matches floating date pills and scroll handles to Light Mode surfaces
  • Preserved the original high-contrast scrollbar appearance in Dark Mode
  • Updated media card video duration badges with subtle Light Mode surfaces while preserving the original translucent dark appearance in Dark Mode
  • Added complete Light Mode support to the Media Viewer top navigation capsule and action controls
  • Added adaptive Light Mode styling to media viewer rotate, frame capture, fit-to-screen, and More actions
  • Updated the media viewer bottom taskbar to adapt seamlessly between Light and Dark themes
  • Restored a pure pitch-black #000000 background and original white controls throughout Dark Mode media viewers
  • Added complete Light Mode support to the single Video Player playback interface
  • Adapted playback controls, time display, speed selector, repeat button, and seek slider for Light Mode
  • Added transparent playback shutter rendering in Light Mode while preserving the pure-black Dark Mode canvas
  • Added complete Light Mode support to the Shorts / TikTok-style vertical video player
  • Updated Shorts Light Mode controls including the floating back button, Favorite, Edit, Trash, Share, More, timeline, and More Options dialog
  • Preserved the original immersive Dark Mode styling throughout the Shorts player
  • Unified capsule styling, gesture handling, high-resolution decoding, memory management, video playback, and theme behavior across the application
