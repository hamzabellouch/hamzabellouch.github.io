Ren Browser version 0.0.3-beta

Hamza Bellouch
CEO & Founder of tknoglobal

We are thrilled to announce the release of Ren Browser v0.0.3-beta! This update introduces an in-app Auto Update engine with channel selection, our dedicated native ren-tor module with embedded binaries eliminating Tor bootstrap stalls, mutual exclusion between Tor and Cloudflare WARP, and refined UI controls throughout.

Dedicated ren-tor Module & Tor Bootstrap Fixes

In this release, we replaced kmp-tor with our dedicated, native-optimized ren-tor module containing embedded binaries. This resolves previous connection stalls and guarantees 100% bootstrap completion. Furthermore, a mutual exclusion system now coordinates Tor routing and Cloudflare WARP, automatically dimming and locking one mode when the other is active to prevent packet collisions and protocol conflicts.
