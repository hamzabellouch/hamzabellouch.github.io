Omicron v0.4.0-beta, 2nd Gen

Hamza Bellouch
CEO & Founder of tknoglobal

We are thrilled to unveil Omicron v0.4.0-beta (2nd Generation)! A historic milestone introducing our self-hosted core download engine, concurrent parallel multi-client extraction across 13 YouTube player clients, integrated audio dub extraction, WhatsApp Status saver with SAF support, and atomic offline thumbnail caching.

2nd Gen Architecture: Self-Hosted Engine & Multi-Client Extraction

Omicron v0.4.0-beta replaces external library wrappers with a brand-new self-hosted engine module (com.tkno.omicron.engine). Powered by native 64-bit binaries (Python 3.12, FFmpeg 7.1.1, Aria2 1.37.0, QuickJS 2025), it executes concurrent parallel stream queries across 13 YouTube player clients for zero format omission, paired with localized audio dub track extraction.

Changes — October 10, 2026

  • Replaced the bulky loading card in the download dialog with a clean progress indicator and two compact capsules displaying active client counts and fetched video counts.
  • Resolved screen flicker during format fetching by isolating state animations from progressive counter updates.
  • Displayed media duration next to the format type icon on video and audio download cards.
  • Added a folder management menu next to refresh in the WhatsApp status saver with Change Folder and Revoke Permission options.
  • Fixed WhatsApp folder permission validation to reliably display the folder permission request card on Android 11 and newer for both standard WhatsApp and WhatsApp Business.
  • Set up automatic initial directory targeting for the SAF storage picker to open directly to the appropriate WhatsApp status media folder.
  • Parallel multi-client extraction using Kotlin Coroutines across web, ios, android, mweb, and tv clients simultaneously.
  • Unified format and subtitle aggregation combining all successful client responses without duplicate streams.
  • Clean format titles with raw format ID numbers removed for a simplified resolution display.
  • Intelligent High, Lite, and Premium badges to distinguish duplicate resolutions of the same codec based on bitrate.
  • Codec-based UI organization separating formats into H.264 / AVC, VP9, and AV1 sections with quick filter chips.
  • Automatic audio pairing appending bestaudio to video-only DASH streams during download task creation.
  • High-speed metadata extraction flags including no-check-formats, no-write-comments, no-write-thumbnail, and player_skip webpage.
  • Network reliability tuning with 10-second socket timeout, 3 extractor retries, and 2 general retries.
  • Simplified general settings by removing redundant client selection options and adopting the 5-client pipeline universally.
  • Display video duration badges on media thumbnails in the Downloads screen.
  • Add smooth sliding pill halo animation with spring physics to the floating bottom navigation bar.
  • Align halo indicator padding symmetrically across all edges for concentric dock styling.
  • Add a toggle switch in Interface and Interaction settings to enable or disable the navigation bar sliding animation.
  • Update the Auto Update channel description wording from pre-release to beta.
  • Store video thumbnails locally inside dedicated tmp/.thumbnails directories with .nomedia protection to prevent gallery indexing.
  • Provide full support for SD Card and custom storage locations via direct filesystem paths and Storage Access Framework.
  • Download thumbnails atomically using temporary files to prevent corrupted or zero-byte images during connection drops.
  • Load thumbnails offline directly from local temp storage across all download lists.
  • Automatically clean up and delete associated thumbnails from all storage locations when a video is removed.
  • Synchronize and rename thumbnail files automatically whenever a downloaded video is renamed.
  • Full support for x86 and x86_64 emulator architectures with optimized per-ABI APK splits.
  • Complete removal of legacy unused gallery-dl code and settings.
  • Reduction of embedded Python package size by stripping unused standard libraries.
  • Removal of redundant Python source metadata and development files to save disk space.
  • Full retention of the aria2c downloader integration and essential zip runtime components.
  • Support for all 13 YouTube player clients with concurrent parallel extraction.
  • Configuration of all 13 player clients as the default setting for complete format discovery.
  • New dedicated player client selection preference in download format settings.
  • Real-time visual progress counter tracking client querying and format discovery.
  • Restoration of all available video resolutions and audio formats during extraction.
  • Migrated the external download library into a dedicated and self-hosted local engine module.
  • Renamed the base package to com.tkno.omicron.engine and refactored core classes to OmicronEngine, EngineRequest, EngineResponse, and EngineException.
  • Removed all external Maven and GitHub dependencies related to youtubedl-android.
  • Integrated and verified native binaries for Python 3.12, FFmpeg 7.1.1, Aria2 1.37.0, and QuickJS 2025 across arm64-v8a, armeabi-v7a, x86, and x86_64 architectures.
  • Eliminated Jackson Databind and Apache Commons-IO dependencies in favor of standard Kotlin IO and native Android JSON handling.
  • Removed unused libffprobe binary files from all target architectures to reduce APK size.
  • Stripped unnecessary static development archives and header files from runtime zip packages to optimize app footprint.
  • Reimplemented the in-app yt-dlp updater using native Android HTTP connections and JSON parsing.
  • Full extraction of all available audio dub languages directly from YouTube metadata without restricting initial stream queries.
  • Dynamic reactivity in the format selection interface ensuring the chosen audio dub track is immediately bound to the download request.
  • Integrated format cards displaying combined video and dubbed audio codecs along with accurate total file sizes and bitrates.
  • Strict filtering of video formats to video-only streams during audio dubbing to prevent conflicts with pre-embedded audio tracks.
  • Standardized MP4 remuxing and container merging across video downloads for universal playback compatibility.
  • Automatic appending of localized audio language names to output file names and task titles when Audio Dub is active.
  • Resetting format selection defaults so audio language always starts as Not specified and video codec filter starts as ALL on every new task.
  • Added a dedicated Status tab to the bottom navigation bar between Downloads and Profile with a custom outlined icon.
  • Implemented Storage Access Framework directory permission handling to access WhatsApp and WhatsApp Business status media.
  • Created an account switcher to browse statuses across WhatsApp, WhatsApp Business, and Saved items.
  • Built a fullscreen media viewer dialog supporting pinch-to-zoom for images and video playback controls.
  • Added action capabilities to save, share, and repost media directly from the viewer and media cards.
  • Implemented category filter chips to filter status items by All, Images, and Videos with live count badges.
  • Added multi-selection mode enabling users to batch download multiple status photos and videos at once.
  • Integrated system MediaStore scanning so saved statuses appear immediately in the device gallery under Omicron folders.
  • Streamlined the Status interface by removing external app shortcuts and seamlessly integrating top controls into the page background.
