Apex — Modern Android Cache Cleaner & System Storage Optimizer

Apex is a high-performance, privacy-focused Android application engineered to inspect storage usage, clear app cache, and optimize system RAM. Operating 100% on-device without ads or background tracking, Apex combines native system APIs with an automated AccessibilityService to perform seamless rootless cache cleaning.

Architecture Showcase
Material Design 3 + Automated Accessibility Cache Cleaning

Architectural & Engineering Highlights

Precision Storage & Cache Inspection

Direct integration with low-level Android APIs (StorageStatsManager & PACKAGE_USAGE_STATS) calculating exact bytecode, cache, and app data footprints in sub-second scans without approximations.

Rootless Automated Cache Cleaning

Custom CacheCleanerAccessibilityService state-machine that automatically navigates system App Info settings to execute batch cache clearing across Samsung OneUI, Xiaomi HyperOS, ColorOS, OxygenOS, and Pixel AOSP.

RAM Optimization & Process Trimming

Monitors real-time total, used, and free RAM via ActivityManager. Trims dormant background processes safely to alleviate system memory pressure and reduce CPU thread contention.

Intelligent System Guardrails & Whitelisting

Built-in protection rules prevent force-stopping essential system services (Settings, SystemUI, Google Play Services, Keyboards, Alarms). Includes custom user whitelist toggles for instant exclusion.

Modern Android Development (MAD)

100% Kotlin with Jetpack Compose, Material Design 3 Dynamic Colors, Coroutines, StateFlow, and LruCache app icon pooling for butter-smooth 120 FPS rendering.

Cleaning Analytics & Historical Trends

On-device history logger (HistoryManager) tracking cumulative gigabytes reclaimed, session cleaning logs, and hardware storage health over time.

Core Modules & Feature Breakdown

Clean Screen

Real-time circular progress gauge showing total accumulated cache size with instant single-tap automated batch clearing.

Stop / RAM Manager

Monitors active background tasks, detects RAM memory bottlenecks, and enables automated batch force-stopping.

Analyze & Statistics

Comprehensive storage category breakdown (Apps, Cache, User Data, System) with historical logs and lifetime freed stats.

Whitelist Protection

Custom whitelist management to easily protect favorite messaging apps, media players, and games from being closed.
