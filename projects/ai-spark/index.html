AI Spark — Local Multi-LLM Broadcast, Comparison & Synthesis Suite

AI Spark is an open-source, local multi-model AI desktop orchestrator and comparative web suite. It simultaneously broadcasts single prompts to ChatGPT, Gemini, and DeepSeek running securely in your browser, displays responses side-by-side in a comparative grid, and leverages Claude to synthesize a comprehensive, non-contradictory final answer with zero paid API costs.

Architecture Showcase
Multi-Model Asynchronous Broadcast & Claude Neural Synthesis

Architectural & Engineering Highlights

Concurrent Multi-LLM Broadcast Engine

High-speed asynchronous asyncio pipeline broadcasting your single query simultaneously across ChatGPT, Gemini, and DeepSeek browser tabs with zero serial queuing latency.

Claude Neural Synthesis Core

Gathers generated responses from all three AI models in real time, parses AST Markdown and code blocks, and prompts Claude to formulate a structured, exhaustive, and unified answer without contradictions.

Dual Modes: Instant & Spark DeepThink

Switch seamlessly between Instant Mode (1-on-1 direct conversation with a single model for rapid prototyping) and Spark Mode (full parallel 3-way multi-model broadcast with automatic Claude synthesis).

Universal Multi-Browser CDP Driver

Native support for Brave, Chrome, Edge, Firefox, and Opera. Connects via Chrome DevTools Protocol (CDP :9222) directly to your default browser profile—preserving existing logins, cookies, and extensions.

Chrome Extension Bridge (Manifest V3)

Features a dedicated WebSocket bridge server (ws://127.0.0.1:41243) connecting an unpackable Chrome Extension for setups where direct profile locking is restricted, enabling zero-restart browser attachment.

100% Local Privacy & Multi-Modal Staging

Zero third-party cloud telemetry. Sessions are saved locally in SQLite (chat_history.db) with full search. Multi-modal files (PDFs, images, docs) are automatically distributed to all active model tabs.

Cross-Platform Setup & Execution

Windows 10 / 11

Initializes isolated .venv_windows, installs requirements, and launches Brave or Chrome in CDP mode:

run_windows.bat
Linux (Ubuntu / Arch / Fedora)

Supports native, Snap, and Flatpak browser binaries with automatic XDG fallback profiles:

chmod +x run_linux.sh
./run_linux.sh
macOS (Intel & Apple Silicon)

Works with system or Homebrew Python 3.11+, setting up .venv_macos automatically:

chmod +x run_macos.command
./run_macos.command
