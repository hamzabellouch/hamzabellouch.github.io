Links version 0.0.4-beta

Hamza Bellouch
CEO & Founder of tknoglobal

This update brings a redesigned interface that preserves the layout you know. It marks a shift to active development with more features coming soon. We welcome your testing and feedback.

A Fresh, Modern UI Built for Speed and Control

Links is an open-source QR code and URL management suite for Android. In Version 0.0.4-beta, we completely revamped the scanning engine with multi-page PDF detection, intelligent Wi-Fi auto-classification, and dynamic target locking.

Key Highlights & Enhancements

  • Scan and extract QR codes directly from multi-page PDF documents with automated detection.
  • Smart Wi-Fi auto-classification with direct one-tap connection and password copying.
  • Intelligent camera viewfinder with dynamic corner snapping and auto-alignment for tilted codes.
  • Comprehensive history management with favorites, multi-format export (TXT, CSV, JSON, XLSX), and backup restore.

How to Test & Join the Beta

We are eager to hear your feedback on the v0.0.4-beta release! You can deploy and test it today from our GitHub repository. If you encounter any bugs or have feature suggestions, please join the discussion on our GitHub issues.
