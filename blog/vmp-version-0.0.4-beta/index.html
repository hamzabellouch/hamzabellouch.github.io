VMP v0.0.4-beta: Modern C++23 Engine, Seamless Title Bar, Sonic DSP & Ultra-Fast Playback

Hamza Bellouch
CEO & Founder of tknoglobal

We are proud to unveil VMP v0.0.4-beta — a massive milestone for our native Linux video player and benchmarking engine. This release modernizes the entire stack to C++23, integrates the menu bar directly into the title bar, introduces Sonic DSP pitch preservation, integrates Linux MPRIS2 desktop controls, and cuts binary footprint from 412MB to under 10MB.

C++23 Modernization, Static Core & Modular Architecture

Under the hood, VMP v0.0.4-beta transitions the entire codebase to the modern C++23 standard. We have decoupled and modularized the playback pipeline into a standalone static core library shared seamlessly across both the OpenGL desktop application and the headless CLI benchmarking suite. The project now also features full unit and integration test coverage managed via CTest and validated automatically through GitHub Actions CI.
